#Null Void
A multiplayer gulag style 2v2 duo FPS shooter game built in unreal engine.
The game features a deathmatch where if a player recieves fatal damage the victim and the killer transported to a void where they battle against each other again. If the killer is able to win again by delivering fatal damage to the victim the killer is transported back to the real world to fight and the victim permanently dies. But if the victim manages to kill the killer both the killer and the victim is transported back to the world to duel once more.
